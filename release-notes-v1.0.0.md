## GrabClip 1.0.0 — first public release 🎉

Download videos, reels, playlists and whole courses to your PC. A simple Windows desktop app, nothing else to install.

### Highlights
- Paste a link, **Analyze**, choose quality, **Download**, with live progress
- YouTube, Facebook, Instagram, TikTok and many more sites
- Video, audio only (MP3, AAC, OPUS, FLAC), 144p up to 4K, WEBM or MP4
- Subtitles (EN / BN), thumbnail + metadata, Fast download
- Download only a part of a video, or a whole **course** into a numbered folder
- Queue, pause / resume, saved queue, Night scheduler, Study mode, auto network retry
- Library with built-in player (resume, notes, speed, next lesson) and **search inside videos**
- Send to phone (QR), smaller 480p copy, extract MP3
- Update yt-dlp button, Check for updates, cookies import, tray + notifications

### Install
1. Download **GrabClip_1.0.0_x64-setup.exe** below (under Assets).
2. Run it. No admin permission needed.
3. If Windows shows a blue warning: **More info → Run anyway** (the installer is not code-signed).

**Requires:** Windows 10 / 11 (64-bit).

Some antivirus programs may flag the installer because yt-dlp and ffmpeg are inside. This is a false positive.
