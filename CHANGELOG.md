# Changelog

All notable changes to GrabClip. Newest first. Format: `## version - date`, then Added / Changed / Fixed.

## 1.0.0

First public release.

- Downloads from YouTube, Facebook, Instagram, TikTok and other sites through yt-dlp.
- Add download popup: Analyze link, quality and format, extras.
- Queue, pause / resume, history, library, search, sort and filter.
- Grab a clip (time range), course folder mode, night scheduler, send to phone (QR).
- Subtitle search, built-in player with resume, notes and speed.
- Update yt-dlp button, saved queue, cookie health, automatic retry, notifications and tray, study mode.
- New GrabClip logo and app icon.
- Closing the window keeps GrabClip in the tray; the tray menu has Add download, Pause / Resume all, Open downloads folder, Library and Quit.
- Settings → Check for updates, and a Support the developer section.
- No browser right-click menu or page reload inside the app; Refresh on Downloads clears the completed rows.
- Only one list preview open at a time.
- Fixed: the Add download popup could be pushed off the window by a very long title.
- Fixed: Send to phone QR code was too dense to scan for files with long names.
