Know what to expect.

The limits, before you install.

  • Designed for Windows 10 and Windows 11, 64-bit.
  • macOS and Linux versions are not currently available.
  • DRM-protected videos and torrents are not supported.
  • Website support can change as the source websites change. Updating yt-dlp often fixes it.
  • Download content you have the right to save, and respect copyright and the source site's terms.
