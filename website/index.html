Questions people ask first

Is GrabClip free?

Yes. GrabClip is free for personal use. Read the licence for the applicable terms.

Does GrabClip upload my links or downloaded files?

No. There are no accounts and no tracking inside the app. GrabClip only talks to the websites you download from, and to GitHub when it looks for an update. Read the privacy page.

Does GrabClip work on macOS or Linux?

Not at the moment. GrabClip supports Windows 10 and Windows 11 on 64-bit systems.

Why does Windows show a security warning?

The current installer is not signed with a paid Windows code-signing certificate, so SmartScreen may show a warning. Download only from the official GitHub release and compare the SHA-256 hash first. Read more.
