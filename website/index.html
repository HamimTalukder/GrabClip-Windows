Open GrabClipGrabClip খোলো

Find it in the Start menu. The first time, a short guide helps you set up cookies.Start menu থেকে খোলো। প্রথমবার কুকিজ সেট করার একটা ছোট গাইড দেখাবে।

Why the warning?সতর্কবার্তা কেন? GrabClip is not code-signed with a Windows certificate yet, because that costs money, so SmartScreen warns about every new app. Some antivirus programs also flag it because yt-dlp and ffmpeg are inside. That is a false positive.GrabClip এখনো Windows সার্টিফিকেট দিয়ে কোড-সাইন করা নয়, কারণ সার্টিফিকেটে টাকা লাগে, তাই SmartScreen প্রতিটি নতুন অ্যাপেই সতর্ক করে। ভেতরে yt-dlp আর ffmpeg থাকায় কিছু অ্যান্টিভাইরাসও ফ্ল্যাগ করতে পারে। এটা ফলস পজিটিভ।

To check your download, compare its SHA-256 with the one on the release page:ডাউনলোড ঠিক আছে কি না দেখতে, রিলিজ পেজের SHA-256-এর সাথে মিলিয়ে নাও: Get-FileHash .\GrabClip_1.0.1_x64-setup.exe -Algorithm SHA256
