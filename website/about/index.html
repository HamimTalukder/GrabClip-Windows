A small project with a practical purpose

Built with curiosity.Designed to get out of your way.

GrabClip is a Windows desktop app built by Hamim Talukder Soton.

Downloads, queue, courses and a local player in one place, so you never juggle a command line and scattered folders.

GrabClip on GitHub GitHub profile Facebook LinkedIn Discord Email

The product

What GrabClip does today: downloads with quality and format control, a queue and scheduler, course folders, a Library and a built-in player. See all features.

The engineering

Built with Tauri and Rust, powered by yt-dlp, FFmpeg and aria2. The open-source tools are used unchanged, and they are credited on the licence page.

The next iteration

Improvements and fixes are published through releases. Follow the changelog, and report bugs or ideas on GitHub Issues.

Support GrabClip.

GrabClip is free for personal use. If it saved you time, you can say thanks. A star on the GitHub repository, or sharing the app with a friend, also helps a lot.
