GitHub Download

Clear about whatstays on your PC.

GrabClip does not require an account or track activity inside the app. It does not upload your URLs or downloaded files. It communicates with the source websites you choose and with GitHub when checking for updates.

Network connections

The app talks to three kinds of places, and only these:

  • The websites you download from. This is how GrabClip reads a link and downloads the media.
  • GitHub. The app asks it for new GrabClip releases, and for the newest yt-dlp when you update the download engine.
  • Public DNS servers, for the Online or Offline label. The app opens a plain connection to check that you are online. Nothing is sent over it.

There is no GrabClip server and no account system, so your links, files and cookies are never sent to the developer.

Local storage

Settings, history, the saved queue, player positions and notes, the search text of subtitles, and cookies are stored in %APPDATA%\GrabClip on your PC. Downloaded files are saved to the output folder you choose in Settings.

Cookies and session security

Cookies you import stay on your PC and can be removed from within the app. GrabClip only hands the file to the download engine on your computer when you download. Your cookies file is your logged-in session, so never share it, attach it to a bug report or show it in a screenshot.

Updates

GrabClip updates are downloaded from GitHub Releases. Each update is digitally signed, and the app installs only a file whose signature matches the key built into GrabClip.

This website

This is a different question from the app, so it has its own answer. This website is static. It has no analytics, no advertising or tracking cookies, and no forms. It loads its fonts, icons and images from itself, not from other companies.

It is hosted on Cloudflare Pages, which, like any web host, processes technical request data such as your IP address in order to deliver the pages. When you press Download, the request passes through this site and sends you on to the installer on GitHub, which serves the file under its own privacy policy. The contact and social links open those services only when you click them.

If this changes, for example if analytics are added, this page will say so.
