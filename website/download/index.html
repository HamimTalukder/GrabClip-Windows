Up and running in a few steps.

Installing takes a minute. Nothing else has to be set up first.

  1. Press Download latest release. The installer comes from the newest GitHub release.
    Prefer to do it by hand? Open the latest release and download the GrabClip_<version>_x64-setup.exe file under Assets. You do not need the .sig and latest.json files, the app uses them for updates.
  2. Run the installer and complete the setup.
  3. Open GrabClip from the Windows Start menu.
  4. Press Add download, paste a link and press Analyze link.

Why is Windows asking whether to run this app?

The current installer is not signed with a paid Windows code-signing certificate, so Microsoft Defender SmartScreen may show a blue "Windows protected your PC" screen.

That warning is about the missing certificate. It does not prove that an installer is either malicious or harmless.

Check the file before you run it

Download GrabClip only from the official GitHub release, which is where the button on this page takes you. Compare the installer's SHA-256 hash with the value shown next to the file on the release page.

Get-FileHash .\GrabClip_1.0.1_x64-setup.exe -Algorithm SHA256

Run that command in PowerShell from the folder that holds the installer. If the two hashes match, click More info, then Run anyway.

If you cannot verify the file, or you are unsure about a security warning, don't continue.

Antivirus warnings

Some antivirus programs flag the installer because yt-dlp and FFmpeg are inside it. Do not assume every alert is harmless. Check the hash against the official release, and look into any detection you cannot explain.

Already using GrabClip?

Check for updates from Settings, Updates. GrabClip also looks for a new version by itself when it starts. If a website stops working, try Update yt-dlp first. Browse the changelog to see what changed in each release.

To uninstall, open Windows Settings, then Apps, and remove GrabClip. Your downloaded videos are never touched.
