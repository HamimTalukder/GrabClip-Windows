Up and running in a few steps.

Installing takes a minute.

  1. Press Download latest release.
    Prefer to do it by hand? Take GrabClip_<version>_x64-setup.exe from the release Assets. Skip the .sig and latest.json files, the app uses them for updates.
  2. Run the installer and complete the setup.
  3. Open GrabClip from the Windows Start menu.
  4. Press Add download, paste a link and press Analyze link.

Why is Windows asking whether to run this app?

The installer is not signed with a paid Windows certificate, so SmartScreen may show a blue "Windows protected your PC" screen. That warning is about the missing certificate. It does not prove a file is harmful or harmless.

Check the file before you run it

Download only from the official GitHub release, which is where the button takes you. Compare the installer's SHA-256 hash with the one on the release page.

Get-FileHash .\GrabClip_1.0.1_x64-setup.exe -Algorithm SHA256

Run it in PowerShell from the installer's folder. If the hashes match, click More info, then Run anyway.

If you cannot verify the file, or you are unsure about a security warning, don't continue.

Antivirus warnings

Some antivirus programs flag the installer because yt-dlp and FFmpeg are inside it. Check the hash, and look into any detection you cannot explain.

Already using GrabClip?

Check Settings, Updates. If a website stops working, try Update yt-dlp first. See the changelog for what changed.

To uninstall, open Windows Settings, then Apps. Your downloaded videos are never touched.
